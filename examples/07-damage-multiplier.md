# Example: Damage Multiplier（伤害倍率）

> 验证基线：CE 7.x / 64 位。文中地址、偏移、字节均为示例占位，需按实际目标替换。

## Scenario
单机本地授权训练中，希望玩家造成的伤害放大 N 倍（如 3×），用于学习在共享伤害计算代码里做数值改写。

## Observation
- 找到「伤害写入受害者血量」的指令 `game.exe+0x...`，由玩家攻击触发。
- 玩家与敌人的攻击都走同一段伤害计算/写入逻辑（共享代码）。
- 回溯伤害值来源：伤害在 `eax` 中计算完成，再由 `mov [rdi+0x10], eax` 写入受害者血量。

## Analysis
直接改血量地址会同时影响显示，不是「伤害倍率」。正确做法是在伤害写入指令注入，把待写入的伤害值 `eax` 乘以系数——且只对「玩家造成的伤害」生效，敌人攻击玩家时不变。属于 `workflows/11` 对象过滤 + 数值改写。

## Implementation
1. AOB 定位伤害写入指令。
2. 判别攻击者是否为玩家（用 team/对象指针，方法见 example 06）。
3. 仅玩家攻击时放大：
   ```pascal
   code:
     mov [rdi+0x10], eax       // 原指令：写入伤害
     push rcx
     mov ecx, eax
     imul ecx, 3                // 伤害 ×3
     mov [rdi+0x10], ecx        // 写回放大后的值
     pop rcx
     jmp return
   ```
4. 非玩家攻击走原分支，不放大。
5. `[DISABLE]` 还原原始字节。

## Verification
- 玩家攻击敌人：敌人血量下降幅度为原来的 3 倍。
- 敌人攻击玩家：玩家受伤幅度不变。
- 反复攻击、重启后仍正确。
