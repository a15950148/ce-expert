# Example: Multi-level Pointer（多级指针 / 重启稳定）

> 验证基线：CE 7.x / 64 位。文中地址、偏移、字节均为示例占位，需按实际目标替换。

## Scenario
单机本地授权训练中，金币/血量的地址每次重启都变，希望找到重启后仍可用的稳定访问路径。

## Observation
- 本次游戏会话金币地址为 `0x1A2B3C4D`，重启后变成 `0x2B3C4D5E`。
- 直接锁定旧地址下次启动失效。
- 该地址的值实际上是从某个"基址 + 偏移"层层解引用得到的。

## Analysis
动态地址，需要 `workflows/04-pointer-scan.md`：以当前地址为起点做指针扫描，逐级回溯到模块基址，得到形如 `game.exe+0x1234 -> +0x10 -> +0x20` 的偏移链。CE 可把结果存为"指针"类型记录，自动解析。

## Implementation
1. 先按已知/未知值找到当前会话的地址（4 Bytes）。
2. 对该地址 `Pointer scan for this address`，重启游戏若干次，逐步剔除不稳定的中间节点。
3. 得到最短/最稳的偏移链（通常 2~4 级）。
4. 在地址列表新建"指针"记录，填入基址（`game.exe+0x1234`）与各级偏移。
5. 重启游戏验证：指针自动解析到新地址，值正确。

## Verification
- 重启游戏后指针记录仍指向正确地址，数值正常。
- 多次重启均稳定（建议 3 次以上）。
- 若指针偶尔失效，缩短偏移链或改用代码访问路径（见 `workflows/03`、`06`）。
