# Example: Money（金币 / 已知数值）

> 验证基线：CE 7.x / 64 位。文中地址、偏移、字节均为示例占位，需按实际目标替换。

## Scenario
单机本地授权训练中，希望把金币改到指定数值，用于学习已知数值的精确修改。

## Observation
- 当前金币显示 `250`，购买一件 `50` 的物品后变为 `200`。
- 这是典型"显示值 = 存储值"的已知数值场景。

## Analysis
数值已知且随操作线性变化，适合 `workflows/01-modify-known-value.md`：先精确数值扫描，再用变化值（减少 50）缩小候选，最后锁定验证。

## Implementation
1. 首次扫描 `Exact Value` / 4 Bytes，值 `250`。
2. 购买后金币变 `200`，再次扫描 `200`（或扫描"减少了 50"）。
3. 候选收敛到 1~几个地址，逐个加入地址列表，手动改成 `999999` 看是否生效。
4. 找到有效地址后，右键 `Find out what writes to this address` 确认来源，或用指针扫描求其稳定路径。

## Verification
- 金币显示变为 `999999`，商店消费后按预期扣减。
- 重启游戏后若地址变化，改用指针/模块偏移，确保可复用（见 `workflows/03-find-dynamic-address.md`）。
- 无游戏崩溃、无异常行为。
