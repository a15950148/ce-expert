# Pointer Scan（指针扫描：多级指针）

## Goal
为动态地址找到一个**重启后仍有效**的指针（基址 + 偏移链），使目标数值可被稳定引用。成功条件：在至少两次重启后，该指针解析出的地址仍指向正确数值。

## Prerequisites
- 已用 `workflows/03-find-dynamic-address.md` 确认地址动态。
- 当前已找到生效地址并加入地址列表。
- 已读 `references/05-pointer-analysis.md`。

## Procedure
1. 在地址列表选中目标地址，右键 → Pointer scan for this address。
2. 设置参数：最大偏移级数（先 4–6 级）、偏移范围、是否允许负偏移。
3. 首次扫描得到大量候选指针，保存结果。
4. 重启目标，重新找到该数值的**新地址**。
5. 回到指针扫描窗口，用新地址重新扫描（Rescan / 用新地址过滤）。
6. 重复「重启 → 重新找地址 → 重新扫描」，直到只剩少数在多次重启中都成立的指针。
7. 选择层数少、基址来自模块（`module+offset`）的指针，添加到地址列表并勾选「自动锁定指针路径」。

## Decision Branches
- 扫描结果空：放宽级数/偏移范围，或确认地址确实动态。
- 重启后无指针存活：指针方案不稳，改用 `workflows/06`/`07` 代码方案。
- 指针偶发失效：见 `diagnostics/04-pointer-does-not-work.md`。

## Verification
- 至少两次独立重启后，指针解析地址正确且数值可控。
- 记录：基址、各级偏移、层数、验证的重启次数。
