# Analyze Data Structure（分析数据结构）

## Goal
还原一个对象在内存中的字段布局（偏移 → 含义），用于稳定引用其成员，并为对象过滤提供判别字段。成功条件：得到一份可复用的偏移表，且关键字段在同类多对象间含义一致、跨场景稳定。

## Prerequisites
- 已找到至少一个对象实例的地址（来自扫描或代码回溯）。
- 已读 `references/06-memory-structure.md`。

## Procedure
1. 在地址列表选中该地址 → 右键 Grouped view，或新建 Structure 并 Add 该地址为实例 1。
2. 触发目标改变该对象的某个状态（如扣血），观察哪个偏移的值随之变化，标注其含义（如 0x10=hp）。
3. 找到另一个同类对象实例（敌人/同伴）作为实例 2，加入同一 Structure，对比各偏移：
   - 含义一致但值不同 → 该偏移是「成员字段」（如 hp 随对象变化）。
   - 含义与值都一致 → 可能是「类级常量/指针」。
   - 完全无关 → 可能是填充或无关数据。
4. 记录稳定偏移表：偏移、类型、含义、是否区分性字段。
5. 把区分性字段（ID/team/type）标记为后续过滤的判别点。

## Decision Branches
- 偏移含义在两次对比间不一致：结构可能含虚表/多态，需按类型分别分析。
- 找不到第二个实例：先用 `workflows/10-identify-player-object.md` 锁定玩家，再找敌人对照。
- 结构随版本变化：保留偏移表，更新后重新校验。

## Verification
- 用偏移表独立读取两个对象的成员，值与预期一致。
- 记录：偏移表、区分性字段、验证的实例数量与场景。
